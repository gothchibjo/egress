## Behaviour matrix

| Situation                          | Behaviour                                            | Test                                         |
| :--------------------------------- | :--------------------------------------------------- | :------------------------------------------- |

## Review notes

- One `platform.System()` selects the mechanism for interfaces, routes,
  resolvers, ICMP and tracing; probes never branch on the OS themselves.
- A missing mechanism changes a result to `skipped` with a stated reason, never
  to `fail`, and never aborts the baseline.
- `capabilities_other.go` compiles for any OS so the packages stay buildable;
  the command itself is limited to `darwin || linux`.
- No check changes meaning between platforms: the check ids, order and evidence
  fields are identical.
